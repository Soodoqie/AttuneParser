# AttuneParser

Аддон для **WoW 3.3.5a** — комплексная аналитика освоения предметов и уровней ковки, планировщик фарма подземелий и рейдов, помощник аукциона, управление инвентарем/банками и автоматизация улучшения экипировки.

## Основные возможности

- **Вкладка «Топ инстов» — рейтинг выгодных локаций:**
  - Показывает подземелья и рейды с наибольшим количеством еще не освоенных предметов, недокованных вещей и потенциальной прибавкой характеристик (от базового уровня до максимальной ступени ковки).
  - Переключение области расчета (*Персонаж* / *Аккаунт*), фильтры по типу (все, подземелья, рейды), дополнению, требуемому уровню, отсутствию КД и исключению тяжелых квестовых цепочек.
  - Поиск по названию предмета или локации, сортировка по рейтингу, количеству вещей или характеристикам, кнопки быстрого перехода к телепорту и открытия в Путеводителе.
- **Вкладка «Обзор и Дары» — сводка прогресса и ресурсов:**
  - Статистика каталога (прогресс персонажа и аккаунта), учет наградных вех с кнопкой быстрого забора, сводка суммарно поглощенных характеристик.
  - Отслеживание активного бонуса дня, эликсиров и гильдейских модификаторов.
  - Подсчет имеющихся реагентов и пыли для улучшения предметов, расчет цепочки конвертации/обмена и кнопка быстрого обмена.
- **Вкладка «Сумки и Ковка» — вещи, хранилища и расщепление:**
  - Единый обзор подходящих предметов в сумках, на персонаже, в личном банке предметов, банке гильдии и хранилище спутника с фильтрами по источнику и статусу.
  - Быстрая продажа уже освоенного лута и массовое расщепление неподходящего/лишнего хлама с предварительной проверкой и фильтрацией вещей, не подлежащих разбору.
- **Вкладка «Настройки» — автоматизация и интерфейс:**
  - Управление параметрами автоматического поглощения (включая фильтр слотов, качества, допуск BoE-вещей), автопродажей освоенных предметов с черным списком и фоновым прогревом клиентского кэша без просадок FPS.
  - Настройка кнопки миникарты, стороны и отображения панели в Путеводителе, уведомлений в чате при обмене предметами с игроками, а также режима связки со спутником.
- **Авто-улучшение экипировки, аукцион и дополнительные модули:**
  - *Прогресс ковки:* панель быстрого выбора целевого уровня улучшения и пошагового авто-улучшения вещей из сумок, с персонажа или банка предметов, с показом текущей ступени ковки прямо в списке, пропуском комплектовых вещей отдельного улучшения и корректным ожиданием подгрузки кэша клиента.
  - *Аукцион:* закрепляемая панель поиска лотов, подходящих для поглощения или докачки ковки, с подсветкой новых/черносписочных вещей и быстрой подстановкой названия в поиск.
  - *Путеводитель:* боковой оверлей со сводкой освоения открытого инста и отметками прогресса на строках добычи.
  - *Вкладка «События и Боссы»:* таймеры мировых боссов, ключи/хранилище эпохальных подземелий и управление связанной автоматикой.

## Скачать и установить (Releases)

1. Откройте страницу последнего релиза: https://github.com/Soodoqie/AttuneParser/releases/latest
2. Скачайте готовый архив **`AttuneParser-v*.zip`** из раздела **Assets** (внутри лежит уже готовая папка `AttuneParser/` без `tests/` и служебных файлов).
3. Распакуйте содержимое архива в `<ПУТЬ_К_WOW>\Interface\AddOns\`.
4. Перезапустите клиент или выполните `/reload` в игре.

Либо клонируйте напрямую через Git:

```powershell
cd "<ПУТЬ_К_WOW>\Interface\AddOns"
git clone https://github.com/Soodoqie/AttuneParser.git AttuneParser
```

## Слэш-команды

- `/ap` или `/attuneparser` — открыть главное окно аддона
- `/ap minimap` — показать или скрыть кнопку у миникарты
- `/ap status` — вывести краткую сводку в чат

## Офлайн-автотесты (`tests/`)

Требуется Python 3.10+ и библиотека `lupa`:

```powershell
pip install lupa
python tests/test_static.py
python tests/test_hardmode_tracks.py
```

- [tests/test_static.py](./tests/test_static.py) проверяет кодировку (UTF-8 без BOM), совместимость символов с WoW 3.3.5a (`<= 0x04FF`), отсутствие запрещенных вызовов (`C_Timer`, `:SetShown(`), баланс скобок/строк, `string.format` и лимит локальных переменных Lua 5.1 (`< 200`).
- [tests/test_hardmode_tracks.py](./tests/test_hardmode_tracks.py) проверяет ключевую логику, интерфейс, аукцион и авто-улучшение экипировки в Lupa-эмуляции (а при наличии соседней папки `../TalorianTP` или `TALORIAN_TP_DIR` дополнительно запускает полную кросс-интеграцию с `TalorianTP`).

## Выпуск новых релизов

1. Обновите `## Version` в [AttuneParser.toc](./AttuneParser.toc), `AP.VERSION` в [AttuneParser.lua](./AttuneParser.lua) и добавьте запись в [CHANGELOG.md](./CHANGELOG.md).
2. Закоммитьте и отправьте изменения в `main`.
3. Создайте тег и отправьте его на GitHub (`git tag v1.1.1 && git push origin v1.1.1`), либо создайте релиз через `gh release create` — workflow [release.yml](./.github/workflows/release.yml) автоматически прогонит автотесты и прикрепит готовый игровой архив `AttuneParser-<tag>.zip`.
